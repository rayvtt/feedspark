  1. The feed is the market’s wired output feed (Google Shopping or the Meta catalogue), streamed into this browser once. Every product is counted; nothing is sampled, nothing is stored, and a re-read reads it again.
  2. A blank is a value. A product with nothing in a field is counted as (blank), so a field that is 40% empty shows it rather than a smaller table.
  3. A product can carry several values. A field repeated across slots (product_highlight 1 to 10, the keyword product_type slots) can be read as all slots, and a list can be split. Such a product is counted once in each of its values, so those shares add to more than 100% — the table says so when it happens.
  4. A reading is a view of the field, never a new one: a category path cut to a tier, text cut into length bands, a price into number bands. The values underneath are untouched.
  5. Filters are AND across fields and OR within one. A table is never filtered by its own selection, so you can still see the values you have not picked.
  6. Styles counts each item group once — a style with a value in any of its sizes counts once for it. A feed with no item_group_id cannot be counted that way and says so.
