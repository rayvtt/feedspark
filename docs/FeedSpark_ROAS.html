How this reads

The breakdown behind every number on this page.
  1. Source. FeedHero's own ROAS dashboard (Google Ads), read via the FeedHero_reports MCP's roas_dashboard tool — the same figures a login at mcp.feedhero.net/reports/roas-dashboard shows. Impressions, clicks, conversions, revenue and spend come from Google Ads; SKUs, zombie% and the category split come from the product feed FeedHero has on file.
  2. Scope, deliberately narrow. FeedHero's client list carries 112 clients — most are not FeedSpark accounts. This page is hard-limited to the seven brands Ray named across every market FeedHero has on file for them. A client outside that list is never pulled, stored or shown.
  3. Three periods, three reads. FeedHero reports a trailing window (7, 30 or 90 days) and nothing finer, so the sync reads each market once per window. Switching the period switches the read — it does not re-cut the same rows.
  4. History is the window as read each day. One point per market per day (a re-read the same day replaces it). A delta "vs 7 days ago" compares the latest trailing figure with the one read a week earlier — the same comparison Google Ads' own previous-period chip makes — and reads "no history yet" until the record is old enough, never a guess.
  5. Sync cadence. The worker pulls FeedHero itself twice an hour (:10 and :40), 5 markets × 3 windows per firing, stalest first — the 57-market roster turns over roughly every 6 hours, well ahead of the source's own ~daily refresh. ⚡ Sync now walks the whole roster in one go (owner only).
  6. Money never crosses a currency. A brand's markets report in different currencies (Superdry alone spans GBP, EUR and USD), so every scorecard, chart, total and blended ROAS on this page runs on the selected currency's markets only; the currency selector names how many markets each one covers.
  7. The band is FeedHero's own verdict — Strong 400%+ ROAS, Steady 200%+, Weak 100%+, Losing under that — never a threshold invented here. A market with no Google Ads activity in the window carries no band at all, which is a different fact from Losing.
  8. Segments. Category is stored by the sync — and FeedHero breaks the category tree down on the 30-day window only: a 7- or 90-day read carries the market's total and its "Unlisted SKUs in Ads traffic" row (Ads traffic on SKUs not in the feed — real spend, tagged not in feed), nothing else. Every other cut — eighteen in all, brand, colour, product age, price type, FeedSpark's optimisation status, custom labels — is read live for any period and cached for six hours; picking one opens the markets in view (up to eight, busiest by clicks first). Price group is not set up in FeedHero for any of the seven brands yet (checked 28 Sep 2026) — a market says so rather than showing an error.
  9. The dashboard modules. Eight cards, each reading the same book as the table — no second fetch. Every money module runs on the selected currency's markets; Data freshness is not money, so it covers every roster market in scope. ⊞ Modules shows, hides and reorders them on this device. Each card's ⬇ saves it as a PNG (captioned with its scope, for a deck) or a CSV (every row behind it, not only those that fit); ⬇ Export saves the whole screen as an Excel workbook (scorecards, each module shown, the table — a tab each, money as numbers beside a Currency column) or a one-page PDF.
