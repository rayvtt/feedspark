How these volume movements are tracked

The quick breakdown behind every number on this page.
  1. 4×-daily live scans. The monitor fetches every wired FeedHero XML feed four times a day (02:15, 08:15, 14:15, 20:15 UTC) — the same pass that powers Label Guard, PT Guard and Golden Record.
  2. Every SKU is fingerprinted. Each scan captures the feed's full set of product IDs, each tagged with its top-level category (the first level of the primary g:product_type).
  3. Days are compared close-to-close. Only the day's last captured set is kept. At the first scan of a new day, yesterday's closing set is compared with today's: IDs that appeared = new in; IDs that vanished = dropped out. Intraday flapping never double-counts.
  4. Categories explain the movement. Every in/out is attributed to its category, and the top movers are stored per day — so "Reiss had 300 in and 900 out" breaks down into the collections that drove it.
  5. History accrues forward. Up to 60 days of daily movement is retained per feed. Tracking started 9 Sep 2026 — bars fill in from the first midnight after each feed's first scan; a catastrophic feed reading is quarantined by the guards' two-strike check before it can fake a movement spike.
