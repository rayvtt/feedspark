How the images are read and tagged

The quick breakdown behind every figure on this page.
  1. Every feed scan reads the whole media estate. The 4×-daily monitor (and ⚡ Scan live here) streams the feed and collects each product's image_link plus every additional_image_link slot, up to ten.
  2. The URL says which shot it is. Within one product, all the images share a long common stem — the SKU, the CDN path, the size suffix. Mask the stem and what is left is the shot code: Monsoon's 01 / 21 / 22, Schuh's m1 / m4 / m8, Reiss's trailing 2…5. Nothing is hardcoded per brand — a retailer we have never scanned yields its own codes on the first pass.
  3. One tag covers thousands of images. The same handful of codes repeats across the whole catalogue, so naming a code names every image that carries it. That is the difference between tagging eleven things and tagging forty thousand.
  4. AI tags by looking, not by guessing. ✦ AI tag sends a sample of that code's actual images to Claude and asks which shot type it is, with a reason. The verdict lands on the code, not on one photograph, and any tag can be corrected by hand — a manual tag always wins.
  5. When there is no convention, we say so. Some feeds (opaque hashed filenames) have no readable pattern; the page marks them unpatterned and falls back to tagging individual images rather than inventing codes that mean nothing.
